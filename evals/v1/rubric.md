# Blinded visual scoring

Score each of six dimensions independently from 0 to 4. Use both screenshots. The anchors below name 0, 2 and 4. Use 1 and 3 for intermediate results. Score the visible work rather than inferred model intent. Consider subject-appropriate conventions and disregard personal palette preferences.

| Dimension | 0 | 2 | 4 |
| --- | --- | --- | --- |
| Hierarchy | The page purpose or main task is hard to locate | The main task is clear after scanning | Focal order serves the task on first glance at both widths |
| Spacing | Elements collide or separation is arbitrary | The composition is legible and mostly regular | Spacing, alignment and responsive density express information structure |
| Typography | Unreadable or without useful distinction | Readable, with basic hierarchy | Deliberate, well-scaled type with strong small-screen legibility |
| Color | Contrast misleads or obscures content | A coherent, readable palette | Color carries state or identity and leaves the task easy to do |
| Accessibility | Essential content or actions appear inaccessible | Basic labels, contrast and focus affordances appear usable | Clear names, status cues and readable layout with corroborating browser evidence |
| Fidelity | The requested task or facts are missing | Core facts are represented with minor misses | Exact supplied facts and requested actions are clear in the visible interface |

For accessibility, score the available visual and supplied browser evidence only. Use a separate browser interaction receipt for a functional or WCAG claim. Explain each score in one specific sentence. A loading, error or blank page counts as a failure before judging. Record every missing attempt. Never invent a score or task result for absent evidence.
