# Albany call slip

An Albany visitor wants to reach Rowan Chen and may need a first sentence
to start the call. Keep the real contact action available even if they
skip the note. State what stays local before the first field. Preserve
all facts and both visits. The tone is a calm, readable appointment slip.
Skip portraits, photography, stock clinic imagery, ornament, and extra
steps. Make the visitor's first sentence the focal detail.

Petroleum #102A2E frames contact, mineral #DDF3EA gives the slip its face,
white mint #F5FAF8 carries the form, sea glass #80D2B3 supports its rules,
slate teal #365F5E carries secondary type, and daylight #F1E472 marks the
call. Baskervville sets the name and the note sentence. Atkinson
Hyperlegible Next sets the clinical facts and controls. On large screens
the contact line spans the top and the editable slip uses the second
column beside the form. On phones the call and stacked form come first.
The example can come below the controls. One optional reveal on preview
adds a physical sense of the slip arriving. Reduce motion to a direct swap.

Start from the clinic feedback about unreadable motion and ambiguous
booking language. Stageshow's authored example frames one real interaction
and gives each change a cause. GOV.UK emphasizes an explicit return to
change answers and preserves entered data. This read used their published
pages. The clinic website returned HTTP 502 and the X search returned
403, so there is no new live capture or engagement count for either.

## Independent live review

The same blind model session rated all four live screens and completed
blank-name recovery, note generation, editing and keyboard return.
The call slip scored **8.15 desktop and 8.15 mobile**. In the same ballot,
the frozen control scored **7.10 desktop and 7.20 mobile**. The reviewer
preferred the call slip's editorial hierarchy and distinct identity.
It found a concrete problem at both widths. Selecting Follow-up visit
left the large example describing a movement assessment.

Keep the existing candidate as the strongest Albany design so far.
The next round should bind the example to the chosen visit without
adding extra interaction or changing the form geometry. A second result
can test draft persistence separately. This is an authored design win.
The 9.5 gate and transfer into installed guidance remain open.

## Selected-visit repair contract

Hold the strongest call-slip composition, type and colors fixed. The
one interaction change is that choosing either visit updates the sample
sentence immediately. Preview still swaps in the person's editable note.
Returning keeps the selected example, visit and name together. Do not
add motion, inputs or a new preview step. Compare the parent and repair
at 320 × 700, 390 × 844 and 1440 × 900. Require the same opening
geometry and recovery, plus the example matching the selected visit.
