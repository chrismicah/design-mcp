# Compact opening and clear result status

A visitor to an independent Albany physiotherapy practice wants to call
a named person and can prepare a short private note. Keep the first
visit simple and calm. Preserve the stated contact facts, labels and
reading order. Omit portraits, claims, pricing, and booking.
The design retains the current nameplate in Bodoni Moda and
Instrument Sans for details and controls. Deep blue #172747 holds
the contact group, pale blue #D7E1FA supports its detail, paper #F0F3FA
and ink #18243A carry the form, and periwinkle #BFCFFF identifies the
call. The caller's ready-to-edit first sentence is the interactive detail.

Freeze Albany before generation. Compare control 9976ef1 and a trial
whose only response changes are the existing compact-opening and
result-action fields. The direction instructs the builder to compress
inter-group gaps to fit the first input and full Preview button at
320 × 700 without reducing control sizes. It also describes a
persistent result status that is cleared on return and directs focus
to the editor. The measured parent is the Madison 84/84 authored
repair. The tested status element is distinct from screen-reader speech.
[Madison browser evidence](https://github.com/chrismicah/design-mcp/blob/16d8c695947fb89e7ce27463f8a3246485cf1795/evidence/benchmark-v1/madison-authored-compact-status.json)
[W3C status messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)

Preserve all other complete unhinted responses in the 48-case suite
and four explicitly requested form responses. Make two clean installs
for each arm. Compare unedited generation with the same brief and
prompt prefix. At 320, 390 and 1440 CSS px require named first-frame
focus, visible local-only wording, blank-name recovery, editable
preview, a cleared result status after keyboard return, and zero
post-load requests. Record functional and blind results separately.
Run a separate blind live review when the generated output passes.

## Exact installed result

The source comparison preserved all 48 complete unrelated replies and
four explicit form overrides. All 73 direction tests passed. Fresh pipx
and uv installs on macOS 15 arm64 passed doctor and the stdio matrix for
both package pins. Both installers reproduced the complete sealed reply
for Albany and the three earlier practice briefs on both arms. The
installed reply is ready for paired, unedited generation. [Installed
receipt](../evidence/benchmark-v1/compact-status-guidance-installed.json)
[Hosted installs](https://github.com/chrismicah/design-mcp/actions/runs/45290625702)

## Albany browser comparison

Both unedited drafts passed 87 of 87 Playwriter checks at 320, 390 and
1440 CSS px. Both exposed their status message on preview, cleared it
on return, and focused the named editable note in the first frame.
Neither made a post-load request. The treatment's preview button ends
37 px higher at 320, 33 px higher at 390 and 105 px lower at 1440.
On desktop it is still fully inside the opening view. Both versions
pass the measured usability floor.
