# Consultation transfer comparison

Measure whether the guidance changes what visitors can do in a generated
website. Pair Albany with the fresh Harbor Estate Law holdout. The two
unhinted source responses must select direct-consultation for both
commits and differ only in the action instruction. Fairhill remains
the separate routing holdout. It can prove route choice but cannot
isolate the draft instruction because the compared directions differ.

Freeze source and installed replies first. Each generation sees the
literal brief, the assigned reply, and the same browser and output
contract. Keep the test phrase and expected repeat behavior with the
evaluator. Use the same model, effort, output cap, and prompt prefix.
Reuse no previous HTML. Archive each first complete draft before
measuring it in Playwriter.

At 320, 390 and 1440 px, find the person, call number, hours and address.
Open the note editor after a blank-name recovery and keyboard visit
selection. Add a new sentence, return to details and preview again with
the same inputs. Record whether the sentence is still present in the
editable control. Change the visit and confirm the editor updates for
that choice. Preserve visible privacy disclosure, keyboard recovery,
and zero post-load requests. Compare matched live scores independently
at desktop and phone widths for any visual promotion claim.

## Harbor first drafts

Both arms used the same prompt prefix and GPT-6.1 Terra at low effort
in separate tool-free sessions. The control generated in 51.82 seconds
and the treatment in 45.78 seconds. The original HTML files are frozen
with their source hashes. The retention result has to come from the
browser replay.
[Generation receipts](../evidence/benchmark-v1/note-retention-harbor-generation.json)
[Exact drafts](../evals/practice_note_retention/cells/harbor-estate-law)

The replay passed 92 of 99 checks in the control and 95 of 99 in the
treatment. Both preserved the exact edited note through a second preview
at 320, 390 and 1440 px. Both generated a fresh note when the topic
changed and made zero post-load requests. The treatment moved the form
higher, but the 320 px opening still puts Preview note below the
viewport, and both phone sizes lose the contact link from view during
preview. The control also starts below the fold at 390 and 1440 px.
Those measurements do not isolate which advice produced the layout
difference on a single generated pair. The specific retention
hypothesis tied. A blind visual score was not assigned to these
functionally incomplete candidates.

## Albany first drafts

The independent generators used the sealed Albany replies under the
same prompt prefix and GPT-6.1 Terra at low effort. Control generated
in 51.25 seconds and treatment in 49.10 seconds. Each passed **99 of
99** browser checks. Both kept the exact edited draft when reopening it
at all three widths, updated the text after a visit change, and made
zero post-load requests. The treatment moved Preview note 62.2 CSS
pixels higher at 320 px. Both fit it in the first viewport. The
behavior hypothesis tied in both Albany and Harbor. Visual judging
of the functionally eligible Albany pair is separate.
[Exact Albany browser comparison](../evidence/benchmark-v1/note-retention-albany-browser.json)


## Albany blind live result

The independent critic exercised the four anonymous desktop and phone
views by keyboard. It recovered from an empty name, changed the visit,
edited the draft, returned to details, and reopened the edited note.
All four views kept the exact edit. Eight original screenshots and
the full interaction trace matched their recorded hashes.

The rubric scored the control **7.70 desktop and 7.70 phone** and the
treatment **7.20 desktop and 7.00 phone**. The control kept the opening
hours and address grouped with the call action and used a rule to mark
the editor's start. The treatment's phone editor introduced a visible
scrollbar and narrowed the available layout by 15 CSS pixels. Both
designs had conventional visual identities. The test used sample
data and left the phone links inactive.

The retention trial is closed without promotion. Both drafts kept the
edit on both briefs. The treatment's earlier opening action on Albany
did not produce a gain in the separate live review.
