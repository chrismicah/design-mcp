# Which design tools should Design MCP beat?

**Use PyModel as the first head-to-head comparison.** It handles the same job: turn a vague request into a design brief, select guidance, then check the result. Refero sets a separate bar for the quality of references. Claude Design sets the bar for how little vocabulary a user needs to revise a screen. The proposed advantage is specific enough to test: can Design MCP make a sound first choice and translate “denser” or “photo first” into a change the user recognizes? ## Coverage limits

The 20 November 2026 search recorded four npm requests (84 distinct packages), four GitHub requests (75 repositories) and 16 official MCP Registry requests (335 server names). The registry’s “design” query reached its final cursor after 229 names. npm and GitHub searches covered ranked slices; duplicate listings and unrelated uses of “design” prevent summing these into a market size. The shortlist favors tools that make decisions about a brief, choose visual references or review the resulting screen. Public contracts and publisher-selected examples support the comparison. ## Beat-them list

Use six briefs covering a landing page, dashboard, mobile flow, portfolio, pricing page and editorial site. Include vague and contradictory requests. Fix assets and brand facts, hold the host model and settings constant for MCP and skill comparisons, and blind the reviewers to the tool. Use plain-agent and current-MCP controls. Keep hosted-product results separate. The thresholds below are proposed pilot gates. [Rationale for cross-output comparisons](../evidence/research/market/studies.md#s2)

1. **Make a better first choice than a reference list.** For each brief, one default call must identify the primary task, first focal element, phone reading order and a source principle adapted to the user's content. Verify all four in the screenshot and source receipt.
2. **Beat a theme swap.** Hide logos, business names and color. At least two of three reviewers must match five of six first drafts to the right job and name a structural cue. Record each comparator’s score and ties.
3. **Earn the extra tool.** Against the same-host frontend-design skill, require two of three reviewers to prefer the candidate for brief fit and distinctiveness on at least four of six pairs. Log the visible reason and task success separately.
4. **Make two reactions sufficient.** Record up to two initial clarification choices separately. Before applying a short reaction, name its visible effect. For “denser,” count actionable rows before and after at 390 px and verify the primary action still works. Log turns and elapsed time.
5. **Judge the finished page and its handoff.** Target five of six combined passes on draft one and six of six within two reactions. Require the squint test, full owner tell sweep, mobile task completion and side-by-side review against two or three genre-appropriate Awwwards references. Include a bland fixture with the banned words removed. Give a second client the accepted direction and check whether it preserves hierarchy and mobile order. Claim a win only against a comparator run on the same briefs.
