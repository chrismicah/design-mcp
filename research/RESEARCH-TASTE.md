# How to build and communicate taste

Visual response, judgment and articulation require different work. People can react to a screenshot rapidly, while an explanation requires identifying what contributed to the reaction. Leder et al. distinguish perception, classification, cognitive mastering and evaluation in a model developed for art. Recognition cues also reduce the need to recall terminology from memory. For this MCP, a reaction can be enough to revise the composition even when the user lacks a design vocabulary. [Leder et al., 2004](https://doi.org/10.1348/0007126042369811) · [Recognition rather than recall](https://www.nngroup.com/articles/recognition-and-recall/) · [Tuch et al., 2012](https://doi.org/10.1016/j.ijhcs.2012.06.003)

| How taste develops | How the MCP can teach it in passing |
| --- | --- |
| Exposure builds familiarity with recognizable moves and helps a viewer locate what is unusual. | Return one contextually matched reference with an observation the agent can use, such as “the issue list shares an edge with the selected issue title.” |
| Vocabulary makes a perceived difference discussable. | Attach a plain consequence to a design term only when useful. “Leave more room around the photograph” can introduce “negative space” if the reader wants the term. |
| Comparison lets a person connect one decision with an observed effect. | In a tie, show small alternatives for the same content. Hold the product facts, navigation, and primary action constant. Change a single major lever. |
| Constraints make selection meaningful. | Fit decisions to actual content, user task, target width, and assets. Choose one distinctive move and say why it fits this screen. |

These mechanisms are product hypotheses informed by fluency, novelty/typicality, and recognition research. Treat learning as a secondary outcome. The primary outcome is how quickly the person gets a usable direction and then a screen they prefer. A short explanation after a choice is more useful here than requiring design terminology up front. [Reber et al., 2004](https://doi.org/10.1207/s15327957pspr0804_3) · [Hekkert et al., 2003](https://doi.org/10.1348/000712603762842147)

## Reactions as concrete changes

| Reaction | Intended visible change | Keep stable in the comparison |
| --- | --- | --- |
| “Calmer” | Give the focal group more room and reduce accent coverage in secondary controls. | Content order, primary action and readable contrast. |
| “Bolder” | Increase the dominant heading or image relative to neighboring elements and strengthen its compositional offset. | Color semantics, landmarks and body reading size. |
| “Too generic” | Replace the least specific major section with an artifact or interaction unique to the product. | Real product facts, user goal and working components. |
| “More like A” | Retain the selected variant’s hierarchy or composition and apply it to the working design. | Project content, brand constraints and accessibility. |

Return a one-line rationale and a small list of expected differences for automated observation. Use the prior direction as revision context. Permit rapid correction of an inferred choice, with the selected default clearly stated. [Amershi et al., 2019](https://www.microsoft.com/en-us/research/publication/guidelines-for-human-ai-interaction/)
